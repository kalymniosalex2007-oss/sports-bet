# GoalPredict – αυτόνομη ιστοσελίδα προγνωστικών ποδοσφαίρου

Node.js (Express + EJS) · SQLite · node-cron · API-Football.

## Εκκίνηση
1. `npm install`
2. `cp .env.example .env` και βάλε το `API_FOOTBALL_KEY` και το `SITE_URL`
3. `npm start` → http://localhost:3000

Στην εκκίνηση κατεβαίνουν αυτόματα οι αγώνες της ημέρας και παράγονται οι αναλύσεις. Δεν χρειάζεται να προσθέτεις τίποτα χειροκίνητα.

## Ποιο API και τι κοστίζει
**API-Football (api-sports.io, v3)**. Απαιτείται API key (δωρεάν εγγραφή στο dashboard.api-football.com).
- **Free**: 100 κλήσεις/ημέρα, 10/λεπτό. Αρκεί για ~10 αναλύσεις/ημέρα (περίπου 5 κλήσεις ανά αγώνα) και όλο το πρόγραμμα. Βάλε `API_DELAY_MS=6500`.
- **Πληρωμένα plans**: πολύ υψηλότερα όρια (έλεγξε τιμές και όρια στο site τους). Τότε αύξησε `MAX_ANALYSES_PER_DAY`, μείωσε το `API_DELAY_MS` και βάλε `ENRICH_TOMORROW=true`.

Endpoints που χρησιμοποιούνται: `/fixtures`, `/predictions` (H2H και στατιστικά), `/standings`, `/injuries`, `/fixtures/lineups`.

## Πώς δουλεύει η αυτόματη ενημέρωση (ώρα Europe/Athens)
| Πότε | Τι κάνει |
|---|---|
| 00:05 κάθε μέρα | Φέρνει αγώνες για σήμερα + `DAYS_AHEAD` ημέρες, δημιουργεί σελίδες και αναλύσεις για σήμερα |
| 11:00, 16:00 | Ανανεώνει απουσίες/τραυματισμούς |
| κάθε 15' | Μόνο αν υπάρχουν αγώνες σε εξέλιξη/σε λίγο: ενδεκάδες (όταν γίνουν επίσημες) και αποτελέσματα |
| 18:00 (προαιρετικά) | Αναλύσεις για αύριο |

Η αρχική σελίδα υπολογίζει την «σημερινή ημέρα» σε κάθε αίτημα με ώρα Αθήνας, άρα στις 00:00 αλλάζει μόνη της. Κάθε αγώνας αποθηκεύεται με `fixture_id` ως primary key (κανένας διπλός αγώνας) και έχει μόνιμο URL `/predictions/home-vs-away` (αν επαναληφθεί το ίδιο ζευγάρι, προστίθεται η ημερομηνία). Οι παλιές σελίδες μένουν για SEO και δείχνουν αν το προγνωστικό βγήκε σωστό.

Χειροκίνητη εκτέλεση: `npm run sync` ή από το Admin Panel.

## Δεδομένα και ειλικρίνεια
- Τίποτα δεν επινοείται: αν λείπουν δεδομένα, η σελίδα το δηλώνει και δεν βγαίνει προγνωστικό.
- Οι ενδεκάδες εμφανίζονται μόνο όταν είναι επίσημες. Οι απουσίες φέρουν σημείωση ότι μπορεί να είναι ελλιπείς.
- Προγνωστικό: μοντέλο Poisson από μέσους όρους γκολ εντός/εκτός έδρας, μπλεγμένο με τις πιθανότητες 1Χ2 του API. Εξετάζονται 1Χ2, Διπλή Ευκαιρία, Over/Under (1.5, 2.5, 3.5) και GG/NG. Επιλέγεται μία μόνο αγορά, και μόνο αν ξεπερνά το 56%. Οι πιθανότητες δεν δείχνονται πάνω από 85%.
- **Δεν έχουν υλοποιηθεί** Ημίχρονο/Τελικό και Κόρνερ: δεν υπάρχουν αξιόπιστα συγκεντρωτικά δεδομένα στο API για να μην είναι αυθαίρετα. Επεκτάσιμο στο `src/predict.js`.
- Δεν δίνονται αποδόσεις ούτε εγγυήσεις. Το project δεν δοκιμάστηκε με πραγματικό API key στο περιβάλλον δημιουργίας (χωρίς δίκτυο): έλεγξε τα πρώτα logs μετά την εκκίνηση.

## Παραγωγή
`pm2 start src/server.js --name goalpredict` πίσω από nginx/Caddy με HTTPS. Κράτα το φάκελο `data/` (SQLite) σε μόνιμο δίσκο.

# v2 – Αναβάθμιση
**Hosting:** το GitHub Pages είναι μόνο στατικό και ΔΕΝ μπορεί να τρέξει αυτό το project (χρειάζεται Node server, βάση, cron). Ανέβασε το repo σε Node hosting (Render, Railway, Fly.io ή VPS). Περιλαμβάνονται `Dockerfile` και `render.yaml`. Η SQLite θέλει μόνιμο δίσκο και ο server πρέπει να είναι πάντα ενεργός για να τρέχουν τα cron.

**Νέα:** AI αναλύσεις (`src/ai.js`), αγορές Ημίχρονο, Ημίχρονο/Τελικό και Κόρνερ (`src/predict.js`), καταγραφή και αυτόματος έλεγχος προγνωστικών (`src/tracking.js`, σελίδα `/stats`), Admin Panel στο `/admin` (`src/admin.js`, απαιτεί `ADMIN_PASSWORD`).

Το παλιό `/admin/run/...?key=ADMIN_KEY` αντικαταστάθηκε από το Admin Panel.
